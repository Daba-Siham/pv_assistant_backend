# Fournisseurs et sites de matériel solaire au Maroc

## Objectif

Ce document aide le chatbot à proposer des pistes de recherche pour comparer ou acheter du matériel photovoltaïque au Maroc.

Important :
- Le chatbot ne doit pas garantir la disponibilité des produits.
- Le chatbot ne doit pas inventer les prix exacts.
- Le chatbot doit toujours conseiller de vérifier la garantie, la compatibilité technique et le devis installateur.
- Les sites sont donnés comme exemples de recherche, pas comme recommandation obligatoire.

## 3. Règles de recommandation par type de matériel

### Panneaux solaires

Pour une installation résidentielle :
- privilégier les panneaux monocristallins ;
- comparer les puissances entre 450 W et 600 W ;
- vérifier la garantie produit et la garantie performance.

Marques à comparer :
- Jinko Solar ;
- LONGi ;
- Canadian Solar ;
- JA Solar ;
- Trina Solar.

### Batteries

Pour hybrid ou off-grid :
- privilégier lithium LiFePO4 si le budget le permet ;
- vérifier la capacité utile ;
- vérifier la compatibilité avec l'onduleur ;
- vérifier le nombre de cycles.

Marques à comparer :
- Pylontech ;
- BYD ;
- Huawei Luna ;
- Dyness ;
- Victron.

### Onduleurs

Pour on-grid :
- onduleur on-grid.

Pour hybrid :
- onduleur hybride.

Pour off-grid :
- onduleur off-grid ou hybride compatible batterie.

Marques à comparer :
- Huawei ;
- SMA ;
- Fronius ;
- Victron ;
- GoodWe ;
- Growatt ;
- Deye.

## 4. Règles de réponse du chatbot

Le chatbot doit dire :
- "Voici des sites à comparer" ;
- "Vérifiez la disponibilité et la garantie" ;
- "Demandez un devis installateur" ;
- "La compatibilité doit être confirmée par un professionnel".

Le chatbot ne doit pas dire :
- "Achetez obligatoirement ce produit" ;
- "Ce prix est garanti" ;
- "Ce matériel est toujours disponible".
