# Guide Inclinaison Photovoltaïque

## Casablanca
Inclinaison recommandée : 30°

Cette inclinaison permet :

- Maximiser la production annuelle.
- Optimiser la réception solaire en hiver et été.
- Réduire les pertes énergétiques.

## Rabat
Inclinaison recommandée : 31°

Cette inclinaison améliore :

- Le rendement global.
- La stabilité de la production.

## Tanger
Inclinaison recommandée : 33°

Cette valeur compense :

- La latitude plus élevée.
- Les variations saisonnières.

## Marrakech
Inclinaison recommandée : 29°

Cette inclinaison favorise :

- La production estivale.
- L'équilibre annuel.
