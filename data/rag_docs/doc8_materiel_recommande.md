# Matériel photovoltaïque recommandé — panneaux, batteries et onduleurs

## 1. Objectif

Ce document aide le chatbot à proposer des types de matériel adaptés à une installation photovoltaïque.

Le chatbot ne doit pas inventer un devis exact. Il doit proposer des familles de matériel et des exemples de marques connues, à vérifier avec un fournisseur local.

## 2. Panneaux solaires

### Panneaux monocristallins haute performance

Recommandés si :
- surface limitée ;
- besoin de bonne production ;
- installation résidentielle moderne.

Exemples de marques :
- Jinko Solar ;
- Canadian Solar ;
- LONGi.

### Panneaux polycristallins économiques

Recommandés si :
- budget limité ;
- surface disponible suffisante.

Exemples de marques :
- JA Solar ;
- Trina Solar ;
- Risen Energy.

### Panneaux premium

Recommandés si :
- priorité à la performance ;
- meilleur rendement recherché ;
- budget confortable.

Exemples de marques :
- SunPower ;
- REC ;
- Panasonic.

## 3. Batteries solaires

### Batterie lithium LiFePO4

Recommandée si :
- installation hybride ;
- installation off-grid ;
- besoin d'autonomie fiable ;
- utilisation quotidienne.

Exemples de marques :
- Pylontech ;
- BYD ;
- Huawei Luna.

### Batterie plomb AGM/GEL

Recommandée si :
- budget limité ;
- usage occasionnel ;
- petite autonomie.

Exemples de marques :
- Victron ;
- Ultracell ;
- Ritar.

### Batterie haute capacité

Recommandée si :
- forte consommation ;
- autonomie de plusieurs jours ;
- installation isolée.

Exemples de marques :
- BYD ;
- Tesla Powerwall ;
- Huawei Luna.

## 4. Onduleurs

### Onduleur on-grid

Recommandé si :
- installation connectée au réseau ;
- pas besoin de batterie.

Exemples de marques :
- Huawei ;
- SMA ;
- Fronius.

### Onduleur hybride

Recommandé si :
- installation avec batterie ;
- besoin de secours en cas de coupure ;
- autoconsommation optimisée.

Exemples de marques :
- Victron ;
- Huawei ;
- GoodWe.

### Onduleur off-grid

Recommandé si :
- maison isolée ;
- absence de réseau électrique ;
- batterie obligatoire.

Exemples de marques :
- Victron ;
- Growatt ;
- Deye.

## 5. Règles de recommandation

Si l'installation est on_grid, recommander :
- panneaux monocristallins ;
- onduleur on-grid ;
- batterie optionnelle.

Si l'installation est hybrid, recommander :
- panneaux monocristallins ;
- onduleur hybride ;
- batterie lithium LiFePO4.

Si l'installation est off_grid, recommander :
- panneaux performants ;
- onduleur off-grid ou hybride ;
- batterie lithium avec capacité suffisante.

Si le budget est limité, proposer :
- scénario économique ;
- réduction ou report d'une partie de la batterie ;
- matériel standard.

Si l'objectif est l'autonomie, proposer :
- batterie plus grande ;
- onduleur hybride ou off-grid ;
- marge de sécurité.

## 6. Important

Les marques sont données comme exemples.

Le choix final dépend :
- du marché local ;
- du stock disponible ;
- des garanties ;
- du devis installateur ;
- de la compatibilité technique.
